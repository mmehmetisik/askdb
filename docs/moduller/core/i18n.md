# i18n.py

## Amac
Turkce/Ingilizce coklu dil destegi saglar. JSON locale dosyalarini yukler ve t() fonksiyonu ile ceviri yapar.

## Bagimliliklari
- `json`, `os`, `functools.lru_cache` -- dosya okuma ve cache
- `fastapi.Request` -- dil tespiti icin

## Fonksiyonlar / Class'lar

| Fonksiyon | Parametreler | Donus | Aciklama |
|---|---|---|---|
| `_load_locale` | `lang: str` | `dict` | JSON locale dosyasini yukler (LRU cache) |
| `t` | `key, lang, **kwargs` | `str` | Anahtari cevirir; bulunamazsa key dondurur |
| `get_lang` | `request: Request` | `str` | X-Lang header'dan dil kodunu okur (varsayilan: tr) |

## Desteklenen Diller
- `tr` (varsayilan), `en`

## Ornek Kullanim

```python
from backend.core.i18n import t, get_lang
lang = get_lang(request)
mesaj = t("auth.invalidCredentials", lang)
```
